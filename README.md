# 💇 Beauty Salon Appointment System

A full-stack web application developed to simplify salon appointment booking and service management through a centralized platform. The system enables customers to browse salon services, book appointments online, and allows administrators to efficiently manage bookings and customer records.

---

## 📖 Project Overview

The Beauty Salon Appointment System was developed as an academic group project to demonstrate practical knowledge of **Web Development, Database Design, Software Engineering, and Relational Database Management**.

The application replaces manual appointment booking with an online system that streamlines appointment scheduling, customer management, and administrative operations.

---

## ❓ Problem Statement

Many small salons still rely on phone calls or manual appointment registers, which often leads to:

- Appointment conflicts
- Time-consuming booking process
- Poor customer record management
- Difficulty tracking appointment history
- Inefficient administrative workflow

This project provides an online appointment management system that automates these tasks.

---

## 🎯 Objectives

- Digitize salon appointment booking
- Reduce manual scheduling efforts
- Manage customer records efficiently
- Organize salon services
- Improve appointment management
- Provide an easy-to-use booking platform
